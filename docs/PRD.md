# ShiftToken — вимоги продукту v1

Костроміна Вікторія Романівна, ІО-36.

## Призначення
Навчальний термінал для обліку часу роботи за карткою: оператор обирає код роботи потенціометром, пред’являє картку, керує паузами та отримує підсумок. Цільова аудиторія — навчальна майстерня. UID є міткою, а не доказом особи; виріб не призначений для оплати праці або контролю доступу. Одночасно відкрита одна сесія. Середовище: Ubuntu 24.04, Docker, STM32 HAL, Wokwi; Nucleo-C031C6.

## Вимоги та приймання
| ID | Поведінка і числовий критерій | Перевірка майбутнього продукту |
|---|---|---|
| FR-01 | MFRC522 опитується кожні 50 мс. Валідні лише UID 4 або 7 байтів після anticollision, перевірки BCC усіх каскадів та SELECT/SAK CRC_A. Відсутність картки не є відмовою SPI. Пред’явлення → підтвердження ≤200 мс. | Картки 4/7 байтів, неправильний BCC/CRC, timer IRQ, відсутній/невірний VersionReg; 30 пред’явлень у S3. |
| FR-02 | Відкрити сесію тільки за новим валідним пред’явленням у READY. Зафіксувати job_code 1–4 з останнього валідного ADC, вік показу ≤150 мс. Зміна ручки під час сесії не змінює її job_code. | Код 1/4; застарілий ADC; обертання ручки після відкриття. |
| FR-03 | Стани READY, ACTIVE, PAUSED, CLOSED, INTERRUPTED. Коротке натискання PAUSE перемикає ACTIVE/PAUSED; CLOSE закриває ACTIVE/PAUSED. Реакція після фізичного натискання ≤100 мс, debounce 25 мс; утримання дає одну подію. | Натискання, утримання, брязкіт, одночасні кнопки (CLOSE має перевагу), неприпустимі переходи. |
| FR-04 | Та сама картка, що утримується, не породжує повторну подію. Нове пред’явлення дозволене лише після 3 послідовних NO_CARD (150 мс). Помилки зчитувача не підтверджують зняття. | Утримання 2 с, коротке зникнення 50 мс, зняття 200 мс, fault між читаннями. |
| FR-05 | active_ms і pause_ms окремо, монотонний час МК, похибка межі інтервалу ≤1 мс відносно часу прийнятої події. Закриті суми незмінні при export. Не оцінювати вимкнений час. | Контрольна сесія: ACTIVE 3000 мс, PAUSED 2000 мс, ACTIVE 1000 мс → 4000/2000 мс; wrap 32-бітного tick. |
| FR-06 | Інша картка під час ACTIVE/PAUSED → CONFLICT без зміни власника або часу. SPI timeout/ID/BCC/CRC error не створює картку. Відмова позначає джерело невалідним, повторна ініціалізація кожні 1000 мс, відновлення ≤1500 мс після доступності. | Дві картки, від’єднання/повернення, повторна ініціалізація; перевірити збереження поточної сесії. |
| FR-07 | UART 115200 8N1: status, pause, resume, close, sessions, export, stats, selftest. Відповідь status/pause/resume/close починається ≤200 мс після LF. export ≤32 записів, завершується ≤3 с у номіналі. Рядок команди ≤63 ASCII, довший відкидається цілком; переповнення лічиться. | Команди у всіх станах, CRLF, невідомі й довгі рядки, потік 20 команд/с, 30 подій під час export/storage. |
| FR-08 | Постійний журнал на microSD SPI, без FAT: 1 сектор 512 B на перехід, magic/version/seq/type/UID/job/state/active_ms/pause_ms/CRC32. Підтвердження переходу лише після запису і read-back CRC; deadline ≤500 мс. 384 записи LBA 128–511; за повного журналу явний STORAGE_FULL, без перезапису. На reset закриті записи відновлюються, останній незакритий → INTERRUPTED, без додавання вимкненого часу. | 100 переходів → reset → побайтне читання; reset посеред запису, CRC-invalid хвіст; заповнення журналу. Bring-up окремого сектора не доводить FR цілком. |

Часові межі — проєктні критерії для людино-керованого термінала: 200 мс залишає запас на 50 мс опитування RFID і RF-обмін; 25 мс debounce відсікає короткі переходи, не вимагаючи швидкого натискання; 500 мс дозволяє обмежений SD busy, а не нескінченне очікування. Це не виміряні результати або гарантії Wokwi. Максимум S3 визначатиме статус вимог.

## Входи, одиниці та валідність
- MFRC522 / SPI: FR-01, 02, 04, 06. Альтернатива PN532 підтримує більше протоколів, але має складніший стек; UART-введення UID не перевіряє зчитувач. UID не фізична величина.
- Дві кнопки / GPIO 3,3 В, active-low із pull-up: FR-03. Одна кнопка з довгим натисканням зменшила б монтаж, проте робить закриття повільнішим і неоднозначним.
- Потенціометр 10 кОм / ADC PA0: FR-02. 12 біт, 0–4095, mV = round(raw·3300/4095); 3300 мВ — номінальна Vref, не калібрування. 8 вибірок із періодом 10 мс; середнє 80 мс, чотири коди з межами 1024/2048/3072 та гістерезисом ±32 counts (≈25,8 мВ). Перші 8 показів прогрівають фільтр; за помилки показ невалідний до нового повного вікна. Альтернатива клавіатура потребує більше GPIO і не дає ADC-каналу для навчальної перевірки.
- microSD / спільний SPI, окремий CS: FR-08. Один статичний буфер 512 B, без файлової системи. Внутрішня flash не вибрана без доказу моделі; RAM не постійне сховище. EEPROM 24LC256 — можливий апаратний варіант, але потребує іншої моделі/шини. Картка з попередніми даними не підходить: стенд використовує окремий образ.

## Межі лабораторних
ЛР1: PRD/джерела, Docker/Git, UART/LED. ЛР2: апаратний фундамент, драйвери, self-test, одночасне опитування, верифікація шин, host-тести та SD bring-up. Сесійний автомат, журнал переходів та FR-02–08 як єдиний продукт реалізуються в ЛР3; FreeRTOS і виміряне порівняння — в ЛР4. Тут немає виміряної baseline ЛР3. ЛР5–6 не визначені без оригінальних завдань.
