# Результат ЛР2

[Остаточний PDF](reports/Лабораторна_робота_2_Вікторія_Костроміна_ІО-36.pdf).

Переносні драйвери MFRC522 і raw microSD, ADC-фільтр та debounce працюють в одному bring-up. Host-перевірки й ARM-збірка пройдені; native Wokwi дає власні SPI/SD/UART/GPIO/ADC-marker записи. Методика та межі — [аналіз трас](captures/lab2/analysis.md); файли й версії — [індекс доказів](evidence/lab2/README.md).

Неузгоджений UID7 моделі відхилено. Фізичні UID7, WUPA утримуваної картки, аналогові параметри та SD power loss не підтверджені. Сесійний продукт належить ЛР3.
